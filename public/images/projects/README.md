# Project Images

Place your project images in this directory. 

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Recommended Size**: 1200x630px (16:9 aspect ratio)
- **File Naming**: Use descriptive names (e.g., `ecommerce.jpg`, `taskmanager.jpg`)

## Current Project Images Needed

Based on `projects.json`, you need the following images:

1. `ecommerce.jpg` - E-Commerce Platform
2. `taskmanager.jpg` - Task Management App
3. `ai-generator.jpg` - AI Image Generator
4. `weather.jpg` - Weather Dashboard
5. `blog.jpg` - Blog Platform
6. `portfolio-gen.jpg` - Portfolio Generator

## Placeholder Images

Until you have your actual project screenshots, you can use placeholder images from:
- [Unsplash](https://unsplash.com/)
- [Pexels](https://www.pexels.com/)
- [Placeholder.com](https://placeholder.com/)

## Optimization

For best performance, optimize your images before adding them:
- Use [TinyPNG](https://tinypng.com/) for compression
- Or use Next.js Image Optimization (automatic)
- Consider using WebP format for better compression
